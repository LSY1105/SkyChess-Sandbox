# SkyChess 服务端黑盒实验设计（B 层）

**目的**：通过单变量受控实验，从「输入 → 输出」的黑盒映射中反推 SkyChess 服务端的经济计算规则，最终支撑完整重建。

---

## 0. 核心原则

| 原则 | 做法 |
|---|---|
| **单变量** | 每次实验只改一个自变量，其余全部固定 |
| **可复位** | 每次实验后把变量改回基线值，再确认状态与基线一致 |
| **基线锚定** | 每个实验批次前后各抓一次基线，漂移即作废重做 |
| **多点采样** | 单点无法区分线性/指数/阶跃 → 每变量至少 5 个取值 |
| **记录扰动** | 记下每次改动的精确值与时间戳 |
| **边界自律** | 只改**你自己航司**的数据；不改市场默认值、不碰裁判端点 |

### B 类 —— 服务端决定（只能观测，不能控制）

| 变量 | 观测方式 |
|---|---|
| 油价 `fuel_prices` | 跨回合观测（裁判设定） |
| 需求曲线 `demand_curve_id=3` | 跨回合观测 |

> C 类只能通过 **A 类实验的输出差异** 间接推断，这是全部实验设计的核心难点。

## 2. 实验矩阵

### EXP-01：运价扫描（P0，最高价值）

**假设**：`passenger_revenue = f(fare)`，且 `f` 含需求弹性

| 项 | 值 |
|---|---|
| 自变量 | `fare`（仅 Simone，Ellington 固定 $250 作对照） |
| 取值 | 60, 90, 120, 150, 180, 210, 240, 300 |
| 基线 | 120 |
| 固定 | 频次 3、机型 APT100、其它所有费用、另一条航线 |
| 观测 | Q4 报表：Passenger Revenue / Load Factor / Passengers(000) / ASK / RPK / Profit |
| 分析 | 画 `revenue(fare)` 曲线找峰值；用 `pax(fare)` 估**价格弹性系数** |
| 判据 | 若 `pax ∝ fare^(-ε)`，则 ε 可估；若出现折点，说明有分段线性（阶梯运价） |

### EXP-02：航线频次扫描（P0）

| 项 | 值 |
|---|---|
| 自变量 | Simone 航线频次 |
| 取值 | 0, 1, 2, 3, 4, 5, 6（受 `max_bh=900` 与 turnaround=60 约束） |
| 基线 | 3 |
| 观测 | ASK、RPK、Load Factor、Cargo(tonnes)、ADU(BH)、各类 Fixed/Direct Operating Cost |
| 分析 | **ASK 应严格线性于频次** → 可直接反推**每次飞行的固定成本**（斜率） |
| 关键 | 这是分离「固定成本 vs 变动成本」的最干净实验 |

### EXP-03：机型替换对照（P0）

| 项 | 值 |
|---|---|
| 自变量 | Simone 航线机型：APT100(100座) → G160(更大) |
| 取值 | 逐次替换，每次只换机型，频次与时刻固定 |
| 观测 | Maintenance Costs、Crew Costs、Fuel Costs、ADU(BH)、座位数、Capacity Utilization |
| 分析 | `dmc_cycle=220`（周期维护）与 `dmc_fh`（飞行小时维护）哪个主导成本 |
| 对照 | 不同航段长度下 `utilization` 的变化 → 反推 `utilization` 计算式 |

### EXP-04：费用项逐项扫描（P1）

对 `landing_fee` / `handling_fee` / `cargo_handling_fee` 分别做 5 点扫描，
观测 **Nav and Landing Costs** 与 **Handling Costs** 的斜率。

> 若斜率 = 1，说明费用是直通的；若 ≠ 1，说明有峰值系数（`peak_landing=1.25`）参与。

### EXP-05：广告/投资投放（P1）

| 项 | 值 |
|---|---|
| 自变量 | Advertising (Agents, Website) 投入额 |
| 取值 | 0, 75k, 150k, 300k, 450k |
| 观测 | **QSI**、Passengers(000)、Route Share、Average Load Factor |
| 分析 | 拟合 `QSI = QSI₀ + k·ln(spend)` 或 `k·spend^α` |
| 判据 | 若 QSI 对 ln(投入) 线性 → 对数饱和模型（广告边际效应递减） |

### EXP-06：航线开关（P0，用于识别固定成本）

| 项 | 值 |
|---|---|
| 自变量 | 撤掉全部航线（频次=0） |
| 观测 | 报表中**仍然存在**的成本项 = 纯固定成本（Ownership / Insurance / Depreciation） |
| 分析 | 直接读出**折旧、保险、贷款利息**的季度金额 |

### EXP-07：跨回合自然观测（P2）

不做任何干预，记录每个回合自动变化的量与油价、GDP、竞争对手动作的共变关系。
这是唯一能观测 B 类变量的途径。

## 3. 实验执行协议（严格按序）

```
每个实验批次：
  1. ./capture.sh exp01-base            # 基线快照
  2. 执行扰动（UI 操作，精确记录改动值）
  3. ./capture.sh exp01-v60             # 变点快照
  4. 复位到基线值
  5. ./capture.sh exp01-base2           # 复位验证
  6. python compare_state.py exp01-base.json exp01-v60.json
  7. 校验 exp01-base2 ≈ exp01-base（若不等 → 环境漂移，本批次作废）
  8. 重复 2-6 直到跑完取值表
```

**记录表**（每次实验都要填）：

| 实验 | 日期 | 变量 | 基线值 | 扰动值 | 快照文件 | 复位校验 | 备注 |
|---|---|---|---|---|---|---|---|
| EXP-01 | 2026-10-22 | fare | 120 | 150 | exp01-v150 | ✓ | |

## 4. 数据分析流水线

```
state-baseline.json
      │
      ├── compare_state.py  →  差异清单（哪些字段变了）
      │
      ├── 报表解析器        →  把 a11y 里的报表数值抽成表
      │
      └── 拟合器            →  用 (输入, 输出) 对拟合服务端公式
            ├── 线性最小二乘      → 固定成本 / 变动成本
            ├── 对数回归          → 弹性、饱和曲线
            └── 分段拟合          → 检测阶梯/断点
```

**产出目标**：每个未知公式对应一张

```
公式名 | 自变量 | 因变量 | 拟合式 | R² | 样本点数 | 证据来源(Evidence ID)
```

## 5. 合法性与边界

**允许**：在你自己的对局中修改**你自己航司**的参数，观察系统响应。
这属于黑盒行为观测，与做实验课记录无异。

**禁止**（我不会协助，也不建议尝试）：
- 调用 `/admin/api/*` 任何端点
- 修改市场默认参数（`market.*`）或裁判配置
- 访问其他玩家、其他对局的数据
- 绕过订阅/付费校验
- 对生产系统做自动化压力测试

## 6. 时间安排建议

| 时段 | 内容 |
|---|---|
| 开放后 30 分钟 | `./capture.sh open` 建立新基线 + 跑 EXP-06（撤航线读固定成本） |
| 第 1 小时 | EXP-01 运价扫描（8 点） |
| 第 2 小时 | EXP-02 频次扫描（7 点） |
| 第 3 小时 | EXP-03 机型对照 |
| 每回合之间 | EXP-07 跨回合观测（不干预） |
| 剩余时间 | EXP-04 / EXP-05 |

> 提示：每次改动后要等**一个回合结算并生成报表**才能观测到财务影响。
> 若系统不允许同回合内反复改价，则每个取值占一个回合 → 6 回合最多跑 6 个点，
> 需要在 EXP-01 与 EXP-02 之间做取舍，优先 EXP-01（信息量最大）。
