# 图表对齐原版（SkyChess 教学沙盘） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让航线需求图、票价网格、小结 KPI、甘特图按**官方界面语义**呈现，并使图上可读出的信息与引擎行为一致。

**Architecture:** 前端渲染层改造集中在 `sandbox/reports.js`（4 个渲染器 + 页签表）；引擎只做**纯增量**：抽出纯函数 `breakEvenLF(rows, fuelPrice)` 并在 `computeTurn` 里把 `routeBE` / `breakEvenLF` 写进 report。所有图表口径取自沙盘**已有**数据（`MARKETS[].dayShape`、`GM.fareBandPeakHours`、`g.schedules`、`detail[].flights`、`peerFares`），**不新建数据模型、不加依赖**。

**Tech Stack:** Node.js 22（运行时零依赖）· 原生 ES module · 手写内联 SVG（`createElementNS` + `viewBox`）· jsdom（仅测试用，项目已有 devDependency）

**Spec:** `docs/superpowers/specs/2026-11-12-图表对齐原版-design.md`

## Global Constraints

- **零新依赖**：不新增 npm 包；KPI 图标用内联 SVG。
- **口径裁定（不可改）**：U1 同一条需求曲线按"是否落在枢纽高峰时段"分两段染（绿=峰时段）＋峰时段背景底纹；U2 用**全局** `GM.fareBandPeakHours`，`fareBands[].peakHours` 只影响定价、**不影响画图**；U3 全局 BE LF 按 ASK 加权；U4 票价网格保留全部市场列；U5 用沙盘席位名。
- **主题不动**：保持暗色石墨（unslop 规范），不得引入浅色改造。
- **数值防护**：所有新增数值渲染必须走 `el()` / `money()` / `num()` / `pct()`；非有限值显示 `'—'`，禁止出现 `NaN`。
- **15 分钟粒度**：一个"时刻" = 15 分钟；全天 06:00–23:00 共 **68** 点（索引 `i = (h-6)*4 + q`，`h∈[6,23]`）。
- **不动文件**：`sandbox/engine.js`、`sandbox/data.js`、`sandbox/server.mjs`（`peerFares` 已下发）。
- **既有坑（§10 项目同步文档）**：模块内不得引用页面的 import 别名；轮询不得整块 `innerHTML` 重建（页签按钮只创建一次、只切 `.on`）。
- **提交前必做**：`node --check`（改了内联 HTML/JS）＋ `node runtests.mjs` 全绿；每个 Task 一次提交，提交信息用中文并沿用仓库前缀（`feat` / `fix` / `test` / `docs`）。

```js
/** 逐航线单班次盈亏平衡 LF ＋ 全网 ASK 加权值（官方界面-13「小结」用）
 *  BE LF = 每班次变动成本 ÷ 每班次满座收入
 *  rows: [{ code, bh, fare, seatsPerFlight, ask }]
 *  纯函数：不读 g、不读时钟 → 可直接单测 */
export function breakEvenLF(rows, fuelPrice) {
  const routeBE = (rows || []).map(x => {
    const ops = perFlightOpsCost(x.bh, fuelPrice);
    const fullRev = x.seatsPerFlight * x.fare;
    return { code: x.code, beLF: fullRev > 0 ? +(ops / fullRev).toFixed(4) : null,
             ask: x.ask || 0 };
  });
  const askSum = routeBE.reduce((a, x) => a + (x.ask || 0), 0);
  const wSum = routeBE.reduce((a, x) => a + (x.ask || 0) * (x.beLF || 0), 0);
  return { routeBE, breakEvenLF: askSum > 0 ? +(wSum / askSum).toFixed(4) : null };
}
```

/** 票价管理「网格」（官方界面-3 + Role Guide p11：实时跟踪竞争对手票价）
 *  列＝市场；格内纵向堆叠各航司报价（航司名 + 加粗价格） */
function fareMatrix(root, g) {
  const codes = Object.keys(MARKETS || {});
  const head = ['市场'].concat(codes.map(c => (MARKETS[c].name || c)));
  const rows = codes.map(code => {
    const mine = (g.routes || []).find(r => r.code === code);
    const peers = (g.peerFares || {})[code] || [];
    const cell = [];
    if (mine) cell.push({ text: 'CA 首都 $' + money(mine.fare).replace('$', '') });
    for (const p of peers) cell.push({ text: (p.name || p.seat) + ' $' + Number(p.fare).toFixed(2) });
    return [code, cell.length ? cell : [{ text: '—', title: '未开通' }]];
  });
  root.appendChild(table(head, rows));
  root.appendChild(el('div', 'small', '官方「网格」选项：实时跟踪各航司票价决策（竞对分析岗用）。'));
}
