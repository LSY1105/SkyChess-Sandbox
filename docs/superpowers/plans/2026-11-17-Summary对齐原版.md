**Goal:** 把 Reports 的 **Summary（总览）** 页签按原版截图补齐两处缺口：
① 六张 KPI 卡的口径与顺序（**第 3 张应为 Market Share，不是 Total Operating Cost**）；
② 原版 Summary 下方的 **COSTS SUMMARY 成本分解图**（目前完全缺失）。

**依据（一手）:** `Reports(VIEW REPORTS)-Summary.jpg`（原版 Summary 页签截图，桌面「学习/德比大学」目录）。
截图事实：六卡 = `Average Load Factor 56%` / `Quality Service Indicator 4.50` / `Market Share 35.91%` / `Break-even Load Factor 56%` / `Margin 0.13%` / `Closing Cash $2,000,000`；下方 `COSTS SUMMARY` 图 = 左列收入三分支（Passenger / Cargo / Ancillary Revenue）→ 中列 `Quarter` 黑条 → 右列 8 个科目（Fuel / Maintenance / Crew / Handling / Nav and Landing / Total Indirect Operating / Total Ownership / Profit）。

**修正前一轮误读:** `docs/superpowers/specs/2026-11-12-图表对齐原版-design.md` §97 与 `plans/2026-11-12-图表对齐原版.md` Task 7 把第 3 张卡记为 `Total Operating Cost` —— 原版该卡是 **Market Share**（`Total Operating Cost` 只作为成本分解图里的科目出现）。本轮一并更正文档。

**Architecture:** 前端全部落在 `sandbox/reports.js`（新增 `costSummaryChart()` + 改 `kpiCards()` / `summary()`）；引擎只做**纯增量 1 行**（把 `invCost` 写进 report，供成本分解图闭合）；**不新建数据模型、不加依赖、不改引擎数值**。

**Tech Stack:** Node.js 22（运行时零依赖）· 原生 ES module · 手写内联 SVG（`createElementNS` + `viewBox`）· jsdom（测试用，项目已有）

## Global Constraints

- **零新依赖**：不新增 npm 包；KPI 图标用内联 SVG path。
- **主题不动**：沿用仓库暗色石墨主题 + 金色强调（`var(--acc)`），**不引入浅色改造**；对齐的是**结构与语义**，不是像素。
- **数值防护**：新增渲染一律走 `el()` / `money()` / `num()` / `pct()`；非有限值显示 `'—'`，禁止出现 `NaN`。
- **不动**：`sandbox/engine.js`、`sandbox/data.js`（成本科目口径见下表）。
- **既有坑（项目同步文档 §10）**：模块内不得引用页面 import 别名；轮询不得整块 `innerHTML` 重建（本轮只新增子树，不改页签机制）。
- **提交前必做**：`node --check` + `node runtests.mjs` 全绿；每个 Task 一次提交，中文提交信息 + 仓库前缀（`feat` / `fix` / `test` / `docs`）。

- [x] **Step 3: 最小实现 —— 数据映射（全部取自已有 report/detail，不新增模型）**

| 图上标签 | 取数 |
|---|---|
| Passenger Revenue | `Σ detail[].rev['Passenger Revenue']` |
| Cargo Revenue | `Σ detail[].rev['Cargo Revenue']` |
| Ancillary Revenue | `Σ detail[].rev['Ancillary Revenue']` +（`revenue` 与三者之差，若有 → 记入 Ancillary 并标注） |
| Fuel Costs | `Σ cost['Fuel'] + Σ cost['Carbon'] + Σ cost['Sustainable Aviation Fuel'] + E.F08_FIXED` |
| Maintenance Costs | `Σ cost['Maintenance'] + E.F07_FIXED` |
| Crew Costs | `Σ cost['Flight Crew'] + Σ cost['Cabin Crew'] + E.F06_FIXED` |
| Handling Costs | `Σ cost['Aircraft Handling'] + Σ cost['Traffic Handling'] + Σ cost['Cargo Handling']` |
| Nav and Landing Costs | `Σ cost['Navigation'] + Σ cost['Landing']` |
| Total Indirect Operating Costs | `Σ cost['Cargo Overheads'] + Σ cost['General & Administration'] + Σ cost['Passenger Services'] + Σ cost['Ticketing, Sales and Promotion'] + report.invCost` |
| Total Ownership Costs | `detail[0].own`（折旧+保险，取**一份**，非各航线重复）+ `detail[0].leasePayments` |
| Profit | `report.operating_profit` |

> `E.F06_FIXED / F07_FIXED / F08_FIXED` 从 `engine.js` 导出 ✔（404,200 / 313,200 / 0）。
> `companyFixed` 已按科目拆进上表三项，故**不单列**。
> **闭合等式**：`Σ 八项 = report.cost`；`Σ 收入 = Σ 八项 + Profit = report.revenue`。
> 不闭合（容差 > $1）时在图下用 `el('div','small',…)` 打印一行提示（不静默）。

(b) **图形**：单张内联 SVG（`viewBox="0 0 900 340"`，宽 100%）：
- 左列 x=0..170：三个收入块，纵向堆叠，块高 ∝ 金额（最小 6px）；
- 中列 x=430..470：`Quarter` 黑色竖条（贯穿整体高度）；
- 右列 x=730..900：8 个科目块，纵向堆叠（顺序同原版：Fuel → Maintenance → Crew → Handling → Nav and Landing → Total Indirect → Total Ownership → Profit），块高 ∝ 金额；
- 连接带：左块右缘 → 中条左缘、中条右缘 → 右块左缘，用**梯形多边形**（上宽下窄由两端厚度决定），填充金色半透明；
- 颜色：块用 `var(--acc)` 系金色渐变（中条纯黑 `var(--tx)`），文字深/浅对比按暗色主题取 `#111`/`#eee`；
- 标签：块内或块右侧 11px 文字；金额显示在块内（`money()` 简写，如 `$200k`）。

(c) `summary()` 内：KPI 卡 → **COSTS SUMMARY 图** → 口径说明 → 明细表（顺序与原版一致：原版是 KPI 卡 → COSTS SUMMARY 图）。

1. Summary 页签六卡顺序 = `Average Load Factor` → `Quality Service Indicator` → `Market Share` → `Break-even Load Factor` → `Margin` → `Closing Cash`，无 `Total Operating Cost` 卡；

4. 未结算（无历史报告）时该图显示「本季尚未结算」提示而非空白/NaN；
5. `node runtests.mjs` 全绿；`node --check` 通过；
6. 小组端与教师端两处 Summary 均生效（同一渲染器）。
