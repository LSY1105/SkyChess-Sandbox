## Rulings

1. **Ruling**：六卡第 3 张按**原版截图**改为 `Market Share`，删除 `Total Operating Cost` 卡
   —— 理由：截图是唯一视觉基准（`Total Operating Cost` 只出现在成本分解图里）
   —— 判断错的代价：与 11-12 旧规格 §97 的记述不一致（已同步更正该规格，避免下个 Agent 再误读）。
2. **Ruling**：成本分解图用**三列流向 SVG**（左收入三分支 / 中 `Quarter` / 右 7 科目 + Profit），不引 d3、不做严格桑基曲线
   —— 理由：仓库零依赖约定；原版是「块 + 连接带」形态，非曲线桑基。
3. **Ruling**：块高按金额比例，但**每块最小 14px 且按可用高度归一化**
   —— 理由：亏损季（`Profit` 为负）若纯比例会把成本块顶出画布（小科目被压成一条线亦不可读）。
4. **Ruling**：公司级固定项（F06 机组 / F07 维修 / F08 燃油）由**前端用 engine 导出常量**归位到对应科目
   —— 理由：不改引擎数值口径；`report.cost` 仍是权威值，图下闭合校验兜底（容差 $1）。
5. **Ruling**：顺带补 `report.rpkTotal`（Summary 明细表 RPK 此前恒 `0.0MM`）
   —— 理由：同一张表内的显性错误，引擎 1 行增量。
6. **Ruling**：成本分解图**仅在本季已结算时渲染**，未结算给提示
   —— 理由：与其它页签「本季尚未结算」口径一致，避免空图。
